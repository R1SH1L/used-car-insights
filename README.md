# Used Car Exploratory Data Analysis

This project cleans and explores a dataset of used cars listed in India. It uses
Jupyter notebooks and Python data-analysis libraries to transform text-formatted
vehicle fields into numeric values and investigate pricing, vehicle
specifications, fuel type, transmission, mileage, and brand-level patterns.

## Project structure

```text
.
├── Analysis.ipynb              # Exploratory analysis and visualizations
├── cleaning.ipynb              # Data cleaning and feature conversion
└── data/
    ├── Used_car_RawData.csv    # Raw input data
    └── cleaned.csv             # Output generated by cleaning.ipynb
```

## Dataset

The raw dataset contains 19,974 listings and 14 columns, including:

- Vehicle identity: `full_name`, `brand_name`
- Prices: `selling_price`, `new_price`
- Vehicle age and usage: `year`, `km_driven`
- Listing details: `seller_type`, `owner_type`
- Specifications: `fuel_type`, `transmission_type`, `mileage`, `engine`,
  `max_power`, and `seats`

The cleaned dataset contains 9,441 complete records. Numeric fields include:

| Column | Description |
| --- | --- |
| `original_price` | Extracted new/on-road price, in lakh units |
| `SP` | Extracted selling price, in lakh units |
| `mileage_cars(kmpl)` | Mileage in kilometres per litre |
| `engine_cc` | Engine displacement in cubic centimetres |
| `maxx_power` | Maximum power in bhp |
| `Kmeter_driven` | Distance driven in kilometres |
| `seat` | Number of seats |

## Data-cleaning workflow

`cleaning.ipynb`:

1. Loads the raw CSV and inspects its structure and missing values.
2. Removes rows containing missing values.
3. Extracts numeric values from prices, mileage, engine, power, kilometres
   driven, and seats.
4. Converts crore, lakh, and rupee-formatted values into comparable lakh-based
   price values.
5. Removes the original text-formatted columns.
6. Writes the result to `data/cleaned.csv`.

## Exploratory analysis

`Analysis.ipynb` loads the cleaned data and creates plots for:

- Number of listings by brand
- Average selling price by brand
- Distribution of listings by model year
- Manual versus automatic transmission
- Mileage by brand and transmission type
- Engine displacement versus maximum power
- Fuel-type counts, mileage, and brand distribution
- Selling price by brand and fuel type
- Differences between average original and selling prices by brand

The notebooks display charts inline; no separate report or model is generated.

## How EDA helped

Exploratory Data Analysis (EDA) helped turn the cleaned listings into
interpretable insights before applying any statistical or machine-learning
method. The visualizations make it easier to:

- Identify which car brands have the most listings and compare their average
  selling prices.
- Understand how vehicle age and kilometres driven are distributed.
- Compare manual and automatic vehicles across brands.
- Examine differences in fuel type, mileage, engine size, and maximum power.
- Investigate relationships between engine capacity, power, mileage, and
  selling price.
- Compare estimated original prices with current selling prices to understand
  depreciation patterns across brands.

Overall, EDA provides a quick way to detect trends, compare vehicle groups,
spot unusual values, and form useful questions for further analysis.

## Requirements

Install Python 3 and the following packages:

```bash
pip install pandas numpy matplotlib seaborn plotly jupyter
```

## Usage

From the project directory, start Jupyter:

```bash
jupyter notebook
```

Run `cleaning.ipynb` first, then run `Analysis.ipynb`.

The cleaning notebook currently reads `data/RawData.csv`, while the raw file
included in this repository is named `data/Used_car_RawData.csv`. Rename the
raw file or update the input path in the first data-loading cell before running
the cleaning notebook. The analysis notebook reads the generated
`data/cleaned.csv` file.

## Notes

- `cleaned.csv` is produced by the cleaning notebook and can be regenerated
  from the raw data.
- Prices are represented in lakh units after cleaning.
- Because the cleaning workflow drops rows with any missing value, the cleaned
  dataset is substantially smaller than the raw dataset.
